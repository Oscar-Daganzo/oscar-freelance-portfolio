# Imágenes de proyectos

Guarda aquí las imágenes que quieras mostrar en la sección «Trabajos».

Recomendaciones:

- Formato WebP.
- Proporción horizontal 4:3.
- Menos de 300 KB por imagen.
- Nombre corto y descriptivo, por ejemplo `stand-modular.webp`.

Después abre `app/content.ts` y sustituye `image: null` por:

```ts
image: "/projects/stand-modular.webp",
```
